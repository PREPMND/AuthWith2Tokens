# AI Usage

## What I Implemented

I independently designed and implemented the core functionality of this project, including:

- Backend architecture with modular folder structure.
- JWT-based authentication using Access Tokens and Refresh Tokens.
- Authentication APIs for user registration, login, logout, token refresh, and protected routes.
- Controllers, Services, Routes, Middleware, Validators, Models, Utilities, and Database connection setup.
- Secure cookie handling for authentication.
- React frontend with protected routing and authentication flow.
- Frontend integration with the backend using Axios and React Query.
- Project testing, debugging, deployment, and documentation.

---

## How AI Assisted

AI (ChatGPT) was used as a development assistant to support learning and improve development efficiency. Specifically, it was used to:

- Explain the JWT authentication flow and Refresh Token mechanism.
- Discuss implementation approaches and best practices.
- Generate an initial reusable API response template, which was later refined and adapted to the project's architecture.
- Assist in debugging and resolving implementation issues.
- Review backend architecture and documentation.
- Help improve the README and project documentation.

## What I Learned

This project helped me strengthen my understanding of:

- JWT Authentication
- Access Token & Refresh Token workflows
- Secure cookie-based authentication
- Modular Express.js backend architecture
- Separation of concerns using Controllers, Services, Routes, Middleware, and Validators
- React Query, especially using **useMutation** for authentication operations such as Login and Signup.
